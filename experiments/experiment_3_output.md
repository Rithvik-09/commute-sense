# Experiment 3 — Expected Output

**Title:** Design a Responsive User Interface Using MediaQuery and LayoutBuilder.

## Expected behavior
- Narrow phone-sized layouts arrange content vertically.
- Wider layouts switch the responsive section to a row-style arrangement.
- MediaQuery reads screen dimensions and orientation.
- LayoutBuilder uses available constraints to choose a layout.
- Flexible and scrollable widgets help reduce overflow.

## Run
Back up lib/main.dart, copy the contents of experiments/experiment_3_responsive_ui.dart into it, then run flutter pub get and flutter run.

Try a narrow phone viewport and a wider emulator/window to compare the layouts.

## Result
The example is intended to adapt to available width. Verify target sizes before submitting screenshots as evidence.
