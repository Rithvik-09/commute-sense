# Experiment 1 — Setup Checklist

- [ ] Flutter SDK is installed.
- [ ] Dart is available through the Flutter installation.
- [ ] Android Studio or VS Code is installed.
- [ ] Flutter/Dart editor extensions are enabled.
- [ ] flutter --version completes successfully.
- [ ] dart --version completes successfully.
- [ ] flutter doctor has been reviewed.
- [ ] An emulator or USB-debugging-enabled phone is available.
- [ ] Git is installed and the repository is cloned locally.

## Useful commands
- flutter doctor
- flutter devices
- dart dart_programs/01_hello_world.dart

A warning in flutter doctor does not always block every target. Resolve the items relevant to the platform you plan to run.
