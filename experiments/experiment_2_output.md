# Experiment 2 — Expected Output

**Title:** Flutter widgets and layouts.

## Expected screen
- An app bar titled Commute Sense.
- A commute banner with a car icon and Smart Commute text.
- A route summary showing Home to College.
- A traffic status card and estimated travel time.
- A Start Commute button.
- A vertically scrollable layout.

## Widgets demonstrated

| Widget | Purpose |
|---|---|
| MaterialApp | Configures the application |
| Scaffold and AppBar | Page structure and top bar |
| Text and Icon | Labels and symbols |
| Container and Card | Group and decorate content |
| Row and Column | Horizontal and vertical layout |
| Stack | Layers banner content |
| ElevatedButton | Primary action |
| SingleChildScrollView | Vertical scrolling |

## Run
From the project root, run flutter pub get and flutter run.

## Result
The app demonstrates a UI composed from Flutter Material widgets. Device rendering has not been verified in this update.
