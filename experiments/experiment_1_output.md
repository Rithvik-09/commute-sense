# Experiment 1 — Expected Output

**Title:** Installation of Flutter & Dart SDK and Introduction to Dart Programming.

## Environment verification
Run flutter --version, dart --version, and flutter doctor after installing Flutter.

Expected result: the first two commands print the installed versions. flutter doctor reports the toolchain status and setup items that may need attention.

## Dart program outputs

| File | Expected output |
|---|---|
| dart_programs/01_hello_world.dart | Prints a Hello World greeting |
| dart_programs/02_variables.dart | Prints declared variable values |
| dart_programs/03_arithmetic_operations.dart | Prints arithmetic operation results |
| dart_programs/04_user_defined_function.dart | Prints a result from a user-defined function |
| dart_programs/05_conditional_statement.dart | Prints the message selected by the condition |

Exact wording and numeric values depend on the statements in each program.

The experiment introduces the Flutter/Dart environment and basic Dart syntax. These are expected outcomes, not a record of live execution.
