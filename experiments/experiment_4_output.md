# Experiment 4 — Expected Output

**Title:** Navigation Between Different Screens Using Navigator and Named Routes.

## Expected behavior
1. The app opens on the Home screen.
2. A navigation action opens another screen, such as Profile or Settings.
3. Direct navigation is demonstrated with Navigator.push and MaterialPageRoute.
4. Named navigation is demonstrated with Navigator.pushNamed and registered routes.
5. Back navigation returns to the previous route.

## Run
Back up lib/main.dart, copy the contents of experiments/experiment_4_navigation.dart into it, then run flutter pub get and flutter run.

## Result
The example demonstrates navigation between screens. Verify each route on a device before using it as practical evidence.
