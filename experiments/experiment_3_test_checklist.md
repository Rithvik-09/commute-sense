# Experiment 3 — Responsive UI Test Checklist

## Narrow screen
- [ ] Open the responsive example on a phone-sized viewport.
- [ ] Confirm the content uses the compact, vertically arranged layout.
- [ ] Scroll through the full content.
- [ ] Check for clipped text or RenderFlex overflow warnings.

## Wide screen
- [ ] Open the example on a tablet-sized viewport or wide emulator.
- [ ] Confirm the wider layout is selected by LayoutBuilder.
- [ ] Check spacing between the panels.
- [ ] Confirm labels and values remain readable.

## Orientation
- [ ] Test portrait orientation.
- [ ] Test landscape orientation.
- [ ] Record the screen width and orientation for each run.

These are manual test steps, not a claim that device testing has already been performed.
