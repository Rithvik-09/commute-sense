# Experiment 1 — Viva Revision

1. **What is Flutter?** A UI toolkit for building applications from a shared codebase.
2. **Which language is used by Flutter?** Dart.
3. **What does flutter doctor do?** Checks the Flutter environment and reports setup status.
4. **What is a variable?** A named storage location for a value.
5. **What is a function?** A reusable block of code that can accept inputs and return a result.
6. **What is a conditional statement?** A statement that selects a path based on a Boolean condition.
7. **What is the difference between print and return?** print writes output; return sends a value to the caller.
8. **How can a Dart file be run?** Use dart path/to/file.dart for a standalone Dart program.
9. **What does null safety help prevent?** Accidental use of absent values without handling them.
10. **Why configure an emulator or device?** To run and inspect a Flutter app on a target platform.
